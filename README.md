# Sistema de Gerenciamento de Biblioteca

Projeto de biblioteca com .NET 8 e Angular.

## Como rodar

Precisa ter Docker instalado.

```
docker-compose build
```

```
docker-compose up -d
```

Depois acessa:
- Frontend: http://localhost:4200
- API: http://localhost:5000

## Parar

```
docker-compose down
```
